    M1 · My games, before there is any game¶
    Who A brand-new player, on a phone, in Greek and in English
    Test id M1 (two tests: Greek, English)
    Needs the local stack
    Catalogue P-17 in CATALOGUE.md

    What this flow is for¶

    The list of «my bookings / my games» is the page a player returns to again and again. The first time they open it, it is empty, and an empty page must not be a dead end: it should say so honestly and offer the next step. This journey also checks that someone who is not signed in is asked to sign in and is brought back to this list afterwards.

    The app has two navigations. The default build (the one the demo runs) calls the tab «Bookings» and opens the bookings list; the booking-navigation build calls it «My games». The journey reads which one it is looking at and checks that one, so the same journey is valid for both.

    The flow at a glance¶

    flowchart TD
    A[Opens «My games» with no account] --> B[«You need an account»<br/>sign-in link remembers the page]
    B --> C[Signs in as a new player]
    C --> D[Home → bottom tab:<br/>Bookings / My games]
    D --> E[Empty list, said plainly,<br/>with a button to find a game]
    E --> F[Pitch search]

    M1 My games: el sign-in return and empty-player navigation¶

    Step 1. Someone who is not signed in opens «My games». The page does not break: it asks them to sign in, and the sign-in link remembers where they were going.

    on screen: open My games without a session: sign in and return here

    Step 2. A brand-new player signs in. They have not booked or joined anything.

    on screen: sign in as a new player with no games

    Step 3. On the home page they tap the bookings tab at the bottom. The list is empty, and says so plainly, with a button that takes them to find a game.

    on screen: home → My games tab → an honest empty state with a way to find a game

    Same moment, on a phone (390 px):

    Step 4. They press that button and land on the list of games near them.

    on screen: find a game from the empty state

    What you should see¶

    • No account: the page does not break; its sign-in link carries next= so the player returns to the list.
    • A new player's list is empty with an explanation and a way to find a game (no blank page).
    • Greek and English both work, at 390 px.
